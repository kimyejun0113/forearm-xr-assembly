# 영상 구성 (약 2분 35초)

화면 위쪽에 **C → R → T → V** 띠를 계속 띄우고, 지금 장면 칸만 파랗게.

| 시간 | 장면 | 화면 | 내용 |
|---|---|---|---|
| 0:00–0:10 | 시작 | 휴대폰 | 책상 위 실제 포어암. 자막: "이 로봇을 설계한 선배가 졸업하면?" |
| 0:10–0:40 | Capture | 휴대폰 → 헤드셋 | 선배(B)가 PPT를 넘기며 설명하고, 후배(A)가 헤드셋으로 "녹화 시작". B가 지식에 없는 새 팁 하나를 말함: "11번 메인 튜브는 넣기 전에 안쪽 먼지를 한 번 불어 줘. 가루가 끼면 끝까지 안 들어가." → A: "녹화 끝" → 처리 대기 구간은 잘라 내고 → "설명 반영 완료 · 새로 배운 말 N문장" 알림 |
| 0:40–1:05 | Represent | 헤드셋 | 실제 로봇 옆에 실물 크기 CAD. "모두 펼치기" → "모두 조립" → "1단계" → "다음"으로 부품이 날아 들어옴. 막힌 부품을 당기면 "먼저 ○○를 빼야 해요" |
| 1:05–1:30 | Transfer ① | 화면 나눔 (헤드셋 + 휴대폰) | "4단계" → "자비스, 렌치 몇 밀리 써?" → "2.5mm 육각 렌치" → A가 실제로 2.5mm 렌치를 집어 볼트를 조임 |
| 1:30–1:50 | Transfer ② (녹화가 이어지는 장면) | 헤드셋 | "11단계" → "자비스, 튜브 넣기 전에 주의할 거 있어?" → 0:30에 선배가 한 말이 나옴. 자막: "30분 전 선배의 말" |
| 1:50–2:10 | Transfer ③ | 화면 나눔 | "14단계" → 실제로 팔을 돌려 보며 "자비스, 팔 돌릴 때 비비는 소리가 나" → "3번의 1밀리 틈부터 다시 봐 주세요." 자막: "14단계 문제 → 3단계 원인" |
| 2:10–2:25 | 다음 사람에게 | 헤드셋 | "조립 완료" → 한마디: "4번 볼트 봉지 꼭 따로 두세요" → "다음 사람" → 새 작업자로 "4단계" → "자비스, 다들 어떻게 했어?" → 방금 남긴 한마디가 나옴 |
| 2:25–2:35 | Verify | PC 화면 | 노트북 기록 화면에서 단계별 어려움 점수 (14단계 3.0 > 4단계 1.67 > 3단계 1.29). 슬라이드 ③으로 넘어가며 설명 |
