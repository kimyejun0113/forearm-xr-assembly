# Quest 3 테스트 안내 (안경 쓰는 사람용)

PC 한 대가 서버를 돌리고, Quest 3는 **같은 Wi-Fi**에서 브라우저로 접속한다. 선으로 연결할 필요는 없다.

## 0. PC 준비 (한 번만)
1. `agent` 폴더에서 PowerShell을 연다.
2. 해커톤 API 키가 있으면 `.env.example`을 `.env`로 복사하고 `LLM_API_KEY=`에 키를 넣는다.
   키가 없어도 화면·단계·검색 답변·PPT 파일 읽기는 된다. **안경 사진 읽기와 음성 인식은 키가 있어야 된다.**
3. 실행:
   ```powershell
   .\run_https.ps1
   ```
   처음 실행하면 인증서를 만들고 `Quest에서 열 주소 → https://192.168.x.x:8443`를 보여 준다.
   Windows 방화벽 창이 뜨면 **허용**을 누른다.

## 1. Quest에서 접속
1. Quest 브라우저에서 위 https 주소를 연다.
2. "연결이 비공개로 설정되어 있지 않습니다"가 뜨면 **고급 → 계속 진행**.
   (같은 Wi-Fi 전용 자체 인증서라서 뜨는 경고. 카메라·마이크는 https에서만 열린다)
3. 카메라·마이크 권한을 물으면 **허용**.

## 2. 설명 듣기 모드 (설계자 발표 기록)
첫 화면의 **● BRIEFING MODE** → 
1. **● CAMERA ON**: 카메라와 마이크를 켠다. 화면에 Quest 카메라 영상이 나오는지 확인.
2. **▶ START BRIEFING**: 설계자가 발표를 시작하면 누른다.
   - 슬라이드가 바뀌면 화면이 잠깐 파랗게 번쩍이며 자동으로 찍힌다 (오른쪽에 사진이 쌓임)
   - 안 찍히면 **⊡ CAPTURE SLIDE**로 직접 찍거나 SENSITIVITY를 낮춘다 (Δ 숫자가 화면 변화량)
   - 잘못 찍힌 사진은 ✕로 지운다
3. **■ STOP BRIEFING** → **⇪ UPLOAD & BUILD KNOWLEDGE**
4. PIPELINE에 단계가 나오고 `DONE ✓`가 되면 지식에 반영된 것.
   - 키가 없으면 사진 단계에서 `비전 읽기에는 LLM_API_KEY가 필요` 오류로 멈춘다 (기존 지식은 그대로)
   - **카메라 대신** UPLOAD FILE에 설계자 PPT(pptx)나 PDF를 넣어도 된다. 키 없이도 되고 더 정확하다.
     pptx의 발표자 노트는 녹음이 없을 때 설계자 말로 쓰인다.

## 3. 조립 모드 (작업자)
첫 화면 → 이름 입력 → **ENGAGE ▸**
- 단계 이동: NEXT / PREV 버튼, 또는 입력창에 "다음", "이전", "3단계"
- 질문: **HOLD TO TALK**를 누른 채 말하기 (키 필요) 또는 입력창에 타이핑
- 명령: "슬라이드 보여줘", "기록 보여줘"(보관함), "닫아", "잘 봐 둬"(장면 표시), "조용히 해 줘"
- 끝: **COMPLETE** → 막혔던 점 한마디 → 다음 작업자에게 전달됨

## 4. 확인할 것 (체크리스트)
| # | 확인 사항 | 해 볼 것 | 정상이면 |
|---|---|---|---|
| 1 | 단계 이동 | "다음" "이전" "10단계" | 위쪽 S01~S14 칸, 원형 게이지, 할 일 목록이 같이 바뀜 |
| 2 | 단계별 정보 | S03, S10, S14로 이동 | S03: 1 mm 틈 주의 · S10: M4×6 + M5×1 · S14 진입 시 빨간 안전 경고 |
| 3 | 음성·의도 | "커넥터 방향 어느 쪽이야?", "M5는 어디에 넣어?", "다음" | 앞의 둘은 답, "다음"은 질문이 아니라 단계 이동 |
| 4 | PPT 인식 | 설명 듣기 모드로 PPT 찍기 또는 파일 올리기 | PIPELINE DONE ✓, 조립 모드 단계 안내에 그 내용이 나옴 |
| 5 | 필요한 것만 안내 | 한 단계에 오래 머물기, 같은 질문 두 번, "조용히 해 줘" | 오래 머물면 한 번만 "도움이 필요하세요?", 묶음(5·10단계) 끝날 때만 부품 확인 알림 |
| 6 | 저장·구조화 | 두 명이 차례로 조립 → 두 번째 사람이 "기록 보여줘", "다들 여기서 어떻게 했어?" | 보관함에 첫 사람의 질문·한마디·★ 장면이 단계별로 보임 |

기록 위치: `data/sessions/<이름>/` (작업자별), `data/briefings/<시각>/` (설명 듣기 원본), `data/kb/aggregate.json` (쌓인 지식).
작업자가 **COMPLETE**를 누르거나 한마디를 남기면 자동으로 모아서 다음 작업자 지식에 바로 반영된다.

## 5. 문제가 생기면
| 증상 | 확인 |
|---|---|
| Quest에서 페이지가 안 열림 | PC와 Quest가 같은 Wi-Fi인지, 방화벽 허용했는지, 주소가 https://…:8443인지 |
| 카메라가 안 켜짐 | 주소가 https인지, 브라우저 권한 허용했는지. Quest 운영체제 버전에 따라 웹에서 패스스루 카메라가 안 열릴 수 있음 → PPT 파일 업로드로 대신 |
| 말해도 반응 없음 | 키가 없으면 Quest에서는 음성 인식이 안 됨 → 입력창 사용 |
| 처리 실패 | PIPELINE 로그, `data/briefings/<시각>/error.txt` |
| 지식을 예전으로 되돌리고 싶음 | `data/kb/history/<시각>/`의 파일을 `data/kb/`, `data/source/`로 복사 후 `python ingest/build_kb.py` |
